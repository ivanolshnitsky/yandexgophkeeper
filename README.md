# GophKeeper

GophKeeper — клиент-серверный менеджер паролей.

## Возможности

- Регистрация и авторизация пользователей (JWT)
- Хранение приватных данных
- Поддержка разных типов данных:
    - логин/пароль
    - текст
    - бинарные данные (упрощённо)
- CLI клиент
- Синхронизация через сервер
- Поддержка storage:
    - in-memory
    - PostgreSQL

---

## Security

- Данные шифруются на сервере (AES-GCM)
- Пароли хэшируются (bcrypt)

## Sync

- Используется поле updated_at
- Стратегия: last write wins
